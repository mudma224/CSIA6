| ID | Position (DS proposal) | Basis / evidence |
|---|---|---|
| **C04** irrigation mapping | DS enum `flood\|basin\|drip\|pivot\|sprinkler\|unknown`. `drip-ui→drip`; `surface-ui→unknown` (not uniquely flood/basin — no silent mapping); `other-ui→unknown`; missing→`unknown`. With `unknown`: water evidence **skipped with a note**, no penalty, no guessed values. Frontend evolution (later M2 revision): replace the 3+unsure choices by 5+unknown; until then the adapter maps. | B0 §2 BLOCKER; honest degradation instead of wrong agronomy; contract v0.2 §2 |
| **C05** crop vocabulary | `src/data/crops.v1.json` (25 crops, 13 in P0 form list, EN+MSA Arabic) is the canonical vocabulary. **Alfalfa ≠ berseem**: two distinct IDs (`alfalfa` = Medicago sativa, observed 138; `berseem_clover` = Trifolium alexandrinum, rotation candidate, unobserved) — the v0.1 conflation is corrected. Free-text history from M2 resolves by exact `crop_id`/`name_en`/`name_ar` match, **no fuzzy matching**; unrecognized → `UNRECOGNIZED_CROP` error. Arabic labels pending team linguistic review. | ground-truth counts (887/138/100/…); data contract tests; B0 §4 |
| **C06** season grammar & unknown | `planned_season` optional, grammar `^\d{4}-\d{4}$` (campaign, consecutive years). `unsure`→omitted. Absent → results returned **season-generic** with warning; season-dependent rules (frost window) skipped with per-option note. History seasons optional per entry, same grammar. | M2 form has `seasonChoice: known\|unsure`; honest degradation; B0 §2 BLOCKER resolved without fabricating a year |
| **C07** baseline | Only `baseline.role = existing_strategy`. Engine baseline = **repeat `history[0]` next season**, scored with the same rules as alternatives. Empty history → `baseline: null` + note (results still returned); never fabricate a baseline from nothing, never claim multi-season strategy from one crop. | B0 §2 BLOCKER; matches "farmer's actual stated strategy" as closely as the M2 form allows |
| **C08** farmer_priorities | Optional. Absent → neutral weights (all 1.0) + explicit note `priorities_not_provided_neutral_weights`. Factor 0–3 → weight 0.5+0.5×v applied **only** to its rule group (documented mapping, deterministic). No hidden arbitrary weights; a later M2 revision may add the optional step. | B0 §2 BLOCKER; no arbitrary defaults |
| **C09** engine method, scores, alternatives | Deterministic rule-based multi-criteria scoring (100 base + documented deltas, clipped [0,100]); every delta carries `rule_id` → `science/engine/rules_table.json` (expression, magnitude, source citation, review status). Score is a **ranking score, never a probability**. Up to **3 alternatives** ranked, ties broken (score desc, crop_id asc); UI displays max 2 (B0 §2). `no_suitable_options` when every candidate is blocked (floor 35) with per-crop reasons — fewer than 3 alternatives is a valid honest outcome. Water evidence always labeled **estimate** (FAO-56 ranges), skipped (null) when irrigation unknown. ML observers (Wheat/Alfalfa 0.864, 3-class 0.843 — criteria v2 met) feed **evidence only**, never recommendations. | rules_table sources: ICARDA/Yigezu 2019 (+20–36 % wheat after faba), Mokrini et al. 2012/2021 (CCN Morocco), PNW/Nebraska extension (SBCN 3–5 yr), WSU/UC IPM (white rot 8–10 yr), FAO-56 (water), POWER T2M_MIN (frost) |
| **C10** statuses/HTTP/versioning | Accept the B0 §5 union unchanged: `results_available`, `no_suitable_options`, `demo_preview`, `model_unavailable` (200 or 503), `request_error` (422 field-coded). Discriminated union on `status`; BFF branches by status; transport errors separate. `contract_version` independent of engine/data versions. Timeouts/rate limits owned by BFF. | B0 §5; D2 guide §5 |
| **C14** validated fixtures & reproducibility | Fixtures generated from **actual engine runs** on fixed inputs (deterministic seed-free rule engine), plus one explicitly labelled `demo_preview` fixture; never the v0.1 example scores (61/78). Model artifacts: `model/` in-repo (joblib hashes in `services/model_api/artifacts/manifest.json`, verified at `/ready`); training pipeline seed 42, re-runnable (`model/01/02/03*.py`). Versions pinned in `services/model_api/requirements.lock.txt`. Independent science review still required before APPROVED. | B0 §6–7; model README; D1 guide §7 |
